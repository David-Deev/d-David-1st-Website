This is the README for my first coding project, which is a website. In this README I will try to describe all the features of my project so that people could replicate it and understand how I built it. Before I begin, I want to give https://stardance.hackclub.com/ a big shoutout!

# Coding Languages Used:

**HTML**: used for structuring the website.
**CSS**: Used for designing the website.
If you don't know these coding languages, you should at least dip your toes in the water and learn a bit here: https://www.w3schools.com/. There are other websites but I prefered this one.

# Features

Here I will describe the main parts of my website and how I built them. 
## **Different Pages**
Includes the Home, Projects and Goals pages.
These are created as seperate HTML files in the website file. They are then refered to each other through navigation  `<a>` anchors and `<href>` links between those pages.
## Navigation Bar
I have a simple navigation bar that is on top horizontally.
PS: For navigation you can checkout: https://www.w3schools.com/css/css_navbar.asp. The examples there show `<li>` and `<ul>`, which are basically lists (explained below). You do not need to have that as mine works fine without them.
## **Special Cursor**
Which is in the shape of a spacerocket.
To create one, I downloaded an image **(2 in credits)**. I then wrote the code for a cursor, a long description of which can be found here: https://blog.logrocket.com/custom-cursor-css/.
PS: My pixelated image is also a downloaded file, so I don't think it requires it's own bulletpoint. ***1 in credits**)
## **Mesh Design**
I used a CSS mesh gradient design.
This is a design where a few colors are chose and then points/lines for those colors are chosen. The colors in between are a mix of those colors, creating a beatiful design. I used a linear gradient, more info can be found here: https://www.w3schools.com/css/css3_gradients.asp. You can further make this choice of colors move accross the screen using CSS animations (https://www.w3schools.com/css/css3_animations.asp).
## **Layout Grids**
I used CSS Flexbox and Grid to show and represent future projects in grid boxes.
More info on how this works can be found here: https://www.w3schools.com/css/css_grid.asp.
## **Linking Websites**
I used (`target="_blank"`) with . This allows people to open the links in new tabs (unlike the navigation links). Here's a link tutorial I refered: https://www.w3schools.com/html/html_links.asp.
